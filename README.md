# figma-design-qa

Скіл для Claude, який знімає з дизайнера рутину гігієни шарів і найменувань у Figma: знаходить `Frame 427`, `Rectangle 12`, `Group 15 copy copy`, дублі імен і розсипані поза фреймами шари, пропонує нормальні назви за змістом і перейменовує — тільки після твого підтвердження.

Що змінилось у кожній версії — у [CHANGELOG.md](CHANGELOG.md) і в [Releases](https://github.com/Kazachek/figma-design-qa/releases).

## Що потрібно

- Claude з уже підключеним і авторизованим **Figma MCP** (разом з ним іде скіл `figma-use`, яким цей скіл користується для перейменування).
- Права на редагування файлу у Figma — інакше скіл зможе лише показати список, але не перейменувати.

## Як підключити скіл

**Claude Code** (термінал або вкладка Code у застосунку Claude). Скопіюй папку `figma-design-qa` з цього репозиторію в `~/.claude/skills/`:

```bash
git clone https://github.com/Kazachek/figma-design-qa.git ~/figma-design-qa-repo
```

```bash
cp -R ~/figma-design-qa-repo/figma-design-qa ~/.claude/skills/
```

Без терміналу: **Code → Download ZIP** на сторінці репозиторію, розпакуй і поклади папку `figma-design-qa` в `~/.claude/skills/`. Скіл підхопиться в наступній сесії Claude.

**Оновлення:** заміни папку `~/.claude/skills/figma-design-qa` новою версією (або `git pull` у клоні й ще раз `cp`). Що нового — у [CHANGELOG.md](CHANGELOG.md).

## Як почати роботу з файлом Figma

1. У Figma виділи фрейм, сторінку чи секцію, яку треба причесати.
2. Правою кнопкою → **Copy/Paste as → Copy link to selection**.
3. Встав посилання в чат з Claude і скажи, що треба, наприклад:
   - «Причеши назви шарів тут: <посилання>»
   - «Прибери Frame 427 і подібне сміття в цьому фреймі: <посилання>»

Що буде далі:
- Якщо в посиланні немає конкретного фрейма, Claude спитає, що саме перевіряти — весь файл чи частину.
- Ти отримаєш список **«було → стане»** з посиланнями на кожен шар. Головні компоненти позначені окремо: їхнє перейменування змінить назву в усіх інстансах.
- Відповідай, що беремо: «так» на все, «1–5 так», «6 назви Header» тощо.
- Claude перейменує тільки підтверджене й коротко підсумує, що змінилось.

Без твого підтвердження у файлі нічого не змінюється.

## Що далі

Зараз скіл уміє тільки гігієну шарів і найменувань. У планах — QA-чекліст перед здачею, аудит текстів і підготовка хендофу для розробки.
