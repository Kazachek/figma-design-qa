# figma-design-qa

Скіл для Claude, який знімає з дизайнера рутину гігієни шарів і найменувань у Figma. Він сам знаходить назви, які Figma ставить за замовчуванням (`Frame 427`, `Rectangle 12`, `Group 15 copy copy` тощо), і перейменовує їх на зрозумілі українські — без зайвих питань. Компоненти й назви, які ти дав сам, він не чіпає.

Що змінилось у кожній версії — у [CHANGELOG.md](CHANGELOG.md) і в [Releases](https://github.com/Kazachek/figma-design-qa/releases).

## Що потрібно

- Claude з уже підключеним і авторизованим **Figma MCP** (разом з ним іде скіл `figma-use`, яким цей скіл користується для перейменування).
- Права на редагування файлу у Figma — інакше скіл не зможе перейменувати шари.

## Як підключити скіл

**Claude Code** (термінал або вкладка Code у застосунку Claude). Скопіюй папку `figma-design-qa` з цього репозиторію в `~/.claude/skills/`:

```bash
git clone https://github.com/Kazachek/figma-design-qa.git ~/figma-design-qa-repo
```

```bash
cp -R ~/figma-design-qa-repo/figma-design-qa ~/.claude/skills/
```

Без терміналу: **Code → Download ZIP** на сторінці репозиторію, розпакуй і поклади папку `figma-design-qa` в `~/.claude/skills/`. Скіл підхопиться в наступній сесії Claude.

**Оновлення:** заміни папку `~/.claude/skills/figma-design-qa` новою версією (або `git pull` у клоні й ще раз `cp`). Що нового — у [CHANGELOG.md](CHANGELOG.md).

## Як почати роботу з файлом Figma

1. У Figma виділи фрейм, з якого почати.
2. Правою кнопкою → **Copy/Paste as → Copy link to selection**.
3. Встав посилання в чат з Claude і скажи, що треба, наприклад:
   - «Причеши назви шарів тут: <посилання>»
   - «Прибери Frame 427 і подібне сміття: <посилання>»

Що буде далі:
- Claude почне з фрейма з посилання, потім пройде всю його сторінку, потім решту файлу. Якщо файл великий, після сторінки він зупиниться й спитає, чи продовжувати.
- Шари з дефолтними назвами він перейменує сам, нічого не питаючи. Назви — українською, за роллю шару: `Шапка`, `Картка товару`, `Кнопка / Купити`, `Іконка / стрілка вниз`, `Фон`.
- Наприкінці ти отримаєш короткий список «було → стане». Якщо Claude в якомусь шарі не впевнений, він покаже його окремо й запропонує назвати інакше або відкотити.
- Щоб повернути старі назви, скажи «відкоти все» або «відкоти 3».

Що він не чіпає ніколи:
- компоненти й інстанси, локальні й з бібліотеки, разом з усім, що всередині них;
- назви, які ти чи хтось інший дали руками;
- положення шарів: нічого не переміщує й не групує, міняє лише назви.

## Що далі

Зараз скіл уміє тільки гігієну шарів і найменувань. У планах — QA-чекліст перед здачею, аудит текстів і підготовка хендофу для розробки.
